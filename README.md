# 九州七日行 2027

## GitHub Pages 發布步驟
1. 登入 https://github.com/ ，右上角按 `+` → `New repository`。
2. Repository name 填 `kyushu-2027`，選 `Public`，按 `Create repository`。
3. 在新 repository 按 `uploading an existing file`。
4. 上傳本資料夾內的 `index.html` 和 `.nojekyll`，按 `Commit changes`。
5. 進入 `Settings` → `Pages`。
6. `Build and deployment` 的 Source 選 `Deploy from a branch`。
7. Branch 選 `main`，資料夾選 `/(root)`，按 `Save`。
8. 通常 1–3 分鐘後，網址會是：`https://你的GitHub帳號.github.io/kyushu-2027/`

## 更新網站
修改後重新上傳並覆蓋 `index.html`，等待約 1–3 分鐘刷新。

## 注意
- GitHub Pages 必須用 `index.html` 作為首頁。
- 請以 GitHub Pages 的 https 網址瀏覽，不要直接從電腦開啟 HTML。
- 圖片目前來自經核對的公開網路圖片縮圖；若圖片來源日後改變，仍可能失效。長期最穩定做法是取得可合法使用的原圖後存入 images/ 資料夾。
